### FieldFunction

允许你根据密度场以及你配置的分隔符来选择要分配哪些物件。密度在每个位置上的值决定分配哪个分隔符对应的物件。

参数：

<table>
  <thead>
    <tr>
      <th width="218.5841064453125">名称</th>
      <th width="205.6929931640625">类型</th>
      <th>描述</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>FieldFunction</td>
      <td>密度槽位</td>
      <td></td>
    </tr>
    <tr>
      <td>Delimiters</td>
      <td>分隔符列表</td>
      <td>将物件附加到密度场的各个值范围。</td>
    </tr>
    <tr>
      <td>Delimiters[].Min</td>
      <td>小数</td>
      <td>分隔符的下界（包含）。</td>
    </tr>
    <tr>
      <td>Delimiters[].Max</td>
      <td>小数</td>
      <td>分隔符的上界（不包含）。</td>
    </tr>
    <tr>
      <td>Delimiters[].Assignments</td>
      <td>Assignments 资产槽位</td>
      <td>提供要使用的物件的分配。</td>
    </tr>
  </tbody>
</table>

### Sandwich

允许你根据物件的垂直（世界 Y 轴）位置以及你配置的分隔符来选择要分配哪些物件。根据每个位置的世界高度，会分配匹配的分隔符所对应的物件。

![](/assets/official-documentation/worldgen/technical-hytale-generator/assignments/sandwich.png)

### Weighted

根据权重和种子随机挑选要分配的物件。

参数：

| 名称                | 类型                               | 描述                                         |
| ------------------- | ---------------------------------- | --------------------------------------------------- |
| Seed                | string                             |                                                     |
| SkipChance          | 小数（0.0–1.0）           | 跳过某个位置而不分配物件的概率。                    |
| WeightedAssignments | 带权重的 Assignments 槽位列表 |                                                     |
| Assignments         | Assignments 资产槽位             |                                                     |
