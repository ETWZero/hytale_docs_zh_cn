### Manual

你可以绘制若干点，并用直线将它们连接起来以创建曲线。这些点之间以直线相连。在第一个点之前以及最后一个点之后，函数保持恒定。

![](/assets/official-documentation/worldgen/technical-hytale-generator/curves/manual.png)

上面的示例展示了一个由 3 个点构成的函数。

### DistanceExponential

DistanceExponential 曲线的形状随 Exponent 值变化，如下图所示。当该曲线的输入接近 Range 值时，输出 0.0。当输入为 0.0 时，该曲线输出 1.0。

![](/assets/official-documentation/worldgen/technical-hytale-generator/curves/distance-exponential.png)

### DistanceS

DistanceS 曲线结合两条 DistanceExponential 曲线，产生类似下图的形状。当该曲线的输入接近 Range 值时，输出 0.0。当输入为 0.0 时，该曲线输出 1.0。通过该资产的参数可以调整曲线的形状。

![](/assets/official-documentation/worldgen/technical-hytale-generator/curves/distance-s-graph.png)

下面是一些使用该曲线的 Positions2D 地形的示例。

![](/assets/official-documentation/worldgen/technical-hytale-generator/curves/positions2d.png)

参数：

<table>
  <thead>
    <tr>
      <th width="162.5050048828125">名称</th>
      <th width="274.6336669921875">类型</th>
      <th>描述</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>ExponentA</td>
      <td>大于 0.0 的小数值</td>
      <td>影响曲线在范围前半段的形状。</td>
    </tr>
    <tr>
      <td>ExponentB</td>
      <td>大于 0.0 的小数值</td>
      <td>影响曲线在范围后半段的形状。</td>
    </tr>
    <tr>
      <td>Range</td>
      <td>大于 0.0 的小数值</td>
      <td>超过该值后，曲线将恒定输出 0.0。</td>
    </tr>
    <tr>
      <td>Transition</td>
      <td>介于 0.0 和 1.0 之间的小数值，可选，默认值为 1.0</td>
      <td>
        接近 0.0 的值会使曲线在 ExponentA 与 ExponentB 之间的过渡更快、更突然。值为 1.0 时，会在整条曲线上从 ExponentA 过渡到 ExponentB。
      </td>
    </tr>
    <tr>
      <td>TransitionSmooth</td>
      <td>介于 0.0 和 1.0 之间的小数值，可选，默认值为 1.0</td>
      <td>
        影响过渡的形状。较低的值在某些情况下会使曲线更尖锐。在设计时尝试不同的值，以体会其效果。
      </td>
    </tr>
  </tbody>
</table>

### Not

对子曲线应用逻辑 NOT 运算。当子曲线的输出为 1 时，输出 0；当子曲线的输出为 0 时，输出 1。介于两者之间的所有数值会按比例缩放。

参数：

| 名称  | 类型       | 描述 |
| ----- | ---------- | ----------- |
| Curve | 曲线槽位 |             |
