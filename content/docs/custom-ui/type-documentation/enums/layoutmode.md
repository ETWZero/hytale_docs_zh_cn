# LayoutMode

## 值

| 名称 | 描述 |
| --- | --- |
| **Full**            | 子元素将填满父元素的全部大小                 |
| **Left**            | 子元素将从左到右排列，并与父元素的左侧对齐   |
| **Center**          | 子元素将从左到右排列，并与父元素的中心对齐   |
| **Right**           | 子元素将从左到右排列，并与父元素的右侧对齐   |
| **Top**             | 子元素将从上到下排列，并与父元素的顶部对齐   |
| **Middle**          | 子元素将从上到下排列，并与父元素的中间对齐   |
| **Bottom**          | 子元素将从上到下排列，并与父元素的底部对齐   |
| **LeftScrolling**   | 子元素将从左到右排列，并与父元素的左侧对齐。启用滚动 |
| **RightScrolling**  | 子元素将从左到右排列，并与父元素的右侧对齐。启用滚动 |
| **TopScrolling**    | 子元素将从上到下排列，并与父元素的顶部对齐。启用滚动 |
| **BottomScrolling** | 子元素将从上到下排列，并与父元素的底部对齐。启用滚动 |
| **CenterMiddle**    | 子元素将从左到右排列——垂直和水平居中         |
| **MiddleCenter**    | 子元素将从上到下排列——垂直和水平居中         |
| **LeftCenterWrap**  | 子元素将从左到右、从上到下排列——水平居中     |
