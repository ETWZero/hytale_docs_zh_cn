# 标记语法

## 标记语法

元素是用户界面的基本构建块。存在各种具有不同属性的元素类型，下文将逐一说明。

语法如下所示：

```
// Basic declaration of an element
// with its Anchor property set to attach on all sides of its parent
// with 10 pixels of margin
Group { Anchor: (Left: 10, Top: 10, Right: 10, Bottom: 10); }

Group { Anchor: (Full: 10); } // More concise version

// Declaration of a Label with a name
// (can be used to access the element from game code)
Label #MyLabel {
  Style: LabelStyle(FontSize: 16); // or just Style: (FontSize: 16), type can be inferred.
  Text: "Hi! I am text.";
}

// Declaration of a Group containing 2 children
// You can use FlexWeight to distribute any left-over space after explicit widths/heights have been subtracted
Group {
  LayoutMode: Left;
  Label { Text: "Child 1"; FlexWeight: 2; }
  Label { Text: "Child 2"; FlexWeight: 1; }
}
```

### 文档

UI 文档（_.ui_ 文件）包含元素树。可以有多个根元素。

### 命名表达式

命名表达式可以在文档的任意层级声明（包括根部），其作用域为该子树，但必须声明在块的开头。

```
// Example of named expressions, declared and used with @ prefix
@Title = "Hytale";
@ExtraSpacing = 5;

Label {
  Text: @Title;
  Style: (LetterSpacing: 2 + @ExtraSpacing);
}
```

你可以使用展开运算符 `...` 复用命名表达式，同时覆盖其部分字段：

```
@MyBaseStyle = LabelStyle(FontSize: 24, LetterSpacing: 2);

Label {
  Style: (...@MyBaseStyle, FontSize: 36);
}
```

你甚至可以这样叠加多个命名表达式：

```
@TitleStyle = LabelStyle(FontSize: 24, HorizontalAlignment: Center);
@SpacedTextStyle = LabelStyle(LetterSpacing: 2);

Label {
  Style: (...@BigTextStyle, ...@SpacedTextStyle);
}
```

#### 文档引用

一个文档可以引用另一个文档，并访问其命名表达式。

```
// Document references are defined with $ prefix
$Common = "../Common.ui";

TextButton {
  Style: $Common.@DefaultButtonStyle;
}
```

### 模板

你可以将一段可复用的界面声明为命名表达式，然后在树中任意多次实例化它，同时对其进行定制。

你可以覆盖局部命名表达式，也可以在模板树的任意位置插入额外的子元素。不过，局部命名表达式必须定义在块的最顶部，位于属性和子元素之前。

```
// This is the template
@Row = Group {
  Anchor: (Height: 50);
  Label #Label { Anchor: (Left: 0, Width: 100); Text: @LabelText; }
  Group #Content { Anchor: (Left: 100); }
};

// Here we'll be using it twice in the document tree
Group #Rows {
  LayoutMode: TopScrolling;

  @Row #MyFirstRow {
    @LabelText = "First row";
    #Content { TextInput {} }
  }

  @Row #MySecondRow {
    @LabelText = "Second row";
  }
}
```

### 属性类型

#### 基本类型

- **Boolean**
  - `Visible: false;`
  - `Visible: true;`
- **Int**
  - `Height: 20;`
- **Float, Double, Decimal**
  - `Min: 0.2;`
- **String**
  - `Text: "Hi!";`
- **Char**
  - `PasswordChar: "*";`
  - _注意：语法与字符串相同，但此类型的值不能包含超过一个字符！_
- **Color**
  - `Background: #ffffff;`&#x20;
- **Objects**
  - `Style: (Background: #ffffff)`
- **Array**&#x20;
  - `TextSpans: [(Text: "Hi", IsBold: true)]`

#### 翻译

翻译键可以在标记中任何可提供字符串的位置引用，元素实例化时它们会被转换为字符串。

**示例：**

```
Label {
  Text: %ui.general.cancel;
}
```

#### 颜色

颜色字面量可以这样书写：

- `#rrggbb`：红、绿、蓝的 6 位十六进制表示（完全不透明）
- `#rrggbb(a.a)`：红、绿、蓝的 6 位十六进制表示，alpha 介于 0 和 1 之间
- `#rrggbbaa`：红、绿、蓝及 alpha 的 8 位十六进制表示

```
Group {
  Background: #000000(0.3);
}
```

<Callout>
  为了可读性，建议优先使用 `#rrggbb(a.a)` 格式，
  而不是 `#rrggbbaa` 格式。
</Callout>

#### 字体名称

字体名称可以通过其字符串 ID 直接引用。内部使用的是名为 `UIFontName` 的自定义类型，不过在标记中字符串会自动转换为该类型。

```
Label {
  Text: "Hi";
  Style: (FontName: "Secondary");
}
```

**可用字体名称**

- _Default_ - 这是大多数文本使用的默认字体，除非指定了其他选项，否则始终使用
- _Secondary_ - 此字体主要用于标题或需要突出的元素
- _Mono_ - 仅用于开发；例如性能分析或错误覆盖层之类。

#### 路径

我们可以使用 `UIPath` 类型引用其他 UI 资源。与 `UIFontName`_,_ 类似，字符串会自动转换为 `UIPath`。路径始终相对于声明它们的文件。在 _Menu/MyAwesomeMenu.ui_ 中查找 _MyButton.png_ 会得到 _Menu/MyButton.png_。如果你想引用位于父文件夹中的文件，可以写两个点（_../MyButton.png_）返回上一级目录。

`UIPath` 的标记语法与字符串相同。（例如 `Path: "Test.png"`）

以下是更多示例：

| UIPath             | .ui 文件                              | 生成的路径        |
| ------------------ | ------------------------------------- | ----------------- |
| MyButton.png       | Menu/MyAwesomeMenu.ui                 | Menu/MyButton.png |
| ../MyButton.png    | Menu/MyAwesomeMenu.ui                 | MyButton.png      |
| ../../MyButton.png | Menu/Popup/Templates/MyAwesomeMenu.ui | Menu/MyButton.png |

#### 对象

对象包含一组属性。在此示例中，我们将一个 Anchor 对象赋给 _Anchor_ 属性：

```
Group {
  Anchor: (
   Height: 10,
   Width: 20
 );
}
```

你可以在[此处](type-documentation#elements)找到可在标记中使用的所有对象。
