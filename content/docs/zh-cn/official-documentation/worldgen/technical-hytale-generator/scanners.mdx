### Origin

仅扫描原点位置。

无参数。

---

### Linear

逐方块线性扫描。

参数：

| 名称    | 类型                       | 描述                                            |
| ------- | -------------------------- | ------------------------------------------------------ |
| Scanner | 可选 Scanner 槽位      | 对由此扫描器扫描的每个方块运行子扫描器。留空则不使用。 |
| Range   | 整数范围              | 要扫描的锚点周围方块范围。                             |
| Axis    | string (`X` \| `Y` \| `Z`) | 扫描所沿的轴。                                         |

---

### Random

按种子决定的随机顺序扫描一行方块。

参数：

| 名称    | 类型                       | 描述                                            |
| ------- | -------------------------- | ------------------------------------------------------ |
| Scanner | 可选 Scanner 槽位      | 对由此扫描器扫描的每个方块运行子扫描器。留空则不使用。 |
| Range   | 整数范围              | 要扫描的锚点周围方块范围。                             |
| Axis    | string (`X` \| `Y` \| `Z`) | 扫描所沿的轴。                                         |
| Seed    | string                     | 决定伪随机顺序。                                       |

---

### Radial

从锚点方块开始，然后由近及远向外移动。

参数：

| 名称    | 类型                  | 描述                                            |
| ------- | --------------------- | ------------------------------------------------------ |
| Scanner | 可选 Scanner 槽位 | 对由此扫描器扫描的每个方块运行子扫描器。留空则不使用。 |
| Bounds  | 整数边界        | 此扫描器在锚点周围的延伸范围。                         |

---

### Queue

依次运行队列中的所有扫描器。

参数：

| 名称     | 类型                  | 描述            |
| -------- | --------------------- | ---------------------- |
| Scanners | Scanner 槽位列表 | 要按顺序运行的扫描器。 |

---

### Imported

导入已导出的扫描器。

参数：

| 名称 | 类型   | 描述      |
| ---- | ------ | ---------------- |
| Name | string | 已导出的扫描器。 |
